Mock — the app

One working screen set: Practice, Library, History, Progress, Settings and first run, with the live session on top. Everything you see is read from the database; sessions you run are written back.

StatusDatabase: {{ dbBadge }}Gemini Live: {{ gemBadge }}

Database. DuckDB-WASM runs in the page (loaded from jsDelivr). Tables: lps, stories, story_lps, questions, files, sessions, answers, settings — seeded with the sample content on first load, snapshotted to localStorage after every write. If the WASM can’t load here, the same queries run over in-memory tables and the badge says so.

Voice. Settings → Gemini Live takes an AI Studio key, a Live model and a voice. The interviewer and coach are one Gemini Live session with three tools — ask_question, coach_feedback, end_session — so the screen knows the question, the LP and the structured verdict, and History gets a real analysis card. Without a key the live screen plays the scripted demo.

Question bank. Seeded from your Exponent export: 233 behavioural questions (98 asked at Amazon), auto-tagged to LPs by keyword — untagged ones are flagged gold. Every question has ✦ Model answer: Gemini writes a STAR answer from your own stories, reproducible by the session seed (set it in the setup sheet; ↻ rolls a new one). The same seed orders the questions a live session draws from.

Backup. Snapshots and session recordings live in IndexedDB (localStorage if that’s blocked). Settings → Library & data: download one JSON backup, restore it, or download the recordings; each session page also has its own Download.

Tweaks: theme · firstRun (forces the setup flow) · voice visual. The default bank came from the first (4 MB) upload; Library → Questions → “Load full Exponent export” streams the complete 18 MB .zst in the browser and adds everything new.
