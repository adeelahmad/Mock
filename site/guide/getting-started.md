# Getting started

Mock is a web app you install like an app. It runs entirely in your browser: your library,
sessions and recordings stay on the device, and it works offline once loaded.

## 1. Open it

Open <a :href="withBase('/app/')" target="_self">the hosted app</a>, or [run it yourself](/run/develop).

## 2. First run

1. **Areas.** Pick what the interview assesses. Load the **AWS interview defaults** (the 16
   Leadership Principles as areas, plus sample stories, questions, files and sessions), or
   import your own [areas CSV](/guide/areas-and-import).
2. **Prep files.** Drop your stories, question lists, resume or notes. Markdown, text, CSV,
   PDF and Exponent `.zst` exports all work.
3. **Gemini API key.** Paste a key from [Google AI Studio](https://aistudio.google.com/apikey).
   It stays on this device and is sent only to Google. Without a key, Mock runs on a built-in
   demo interviewer, so you can try everything first.
4. **Say hello.** A short mic check confirms the interviewer can hear you.

## 3. Install it

- **iPhone / iPad:** Safari → Share → *Add to Home Screen*. This also stops Safari clearing the
  data of a site you haven't opened in a while.
- **Android, desktop Chrome or Edge:** the *Install* notice on Practice, or the install icon in
  the address bar.

## 4. Practise

Practice suggests today's drill from your weakest areas. Start it, answer out loud, listen to
the coach, and say "next". Every session lands in History with a recording, a card per answer
and a report.

## 5. Back up

Settings → Library & data → *Back up*. Practice reminds you when the last session isn't in a
backup yet. Or [sign in](/guide/sync) and let the server keep a copy.
